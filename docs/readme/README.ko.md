**그 밖에도:**

- **비교** — 서명 2~6개를 나란히 살펴봅니다.
- **가져오기와 내보내기** — 사람, 서명, 검증, 결정이 담긴 작업 공간 전체를 파일 하나로 불러옵니다.
- **기록과 CSV 내보내기** — 모든 검증, 결정, 메모를 검색할 수 있습니다.
- **라이트와 다크 테마** — 휴대폰부터 데스크톱까지 맞는 레이아웃.
- **개인정보 우선 설계** — 서명은 이 컴퓨터에만 저장됩니다.

## 모델 기능

작성자 종속 오프라인 서명 검증. 각 작성자는 **진짜 서명 12개만으로, 위조 서명 없이** 등록됩니다.

### 방법 (요약)

서명은 쌍으로 비교됩니다. 작성자의 진짜 서명 쌍만으로 학습한 모델이 의심 서명을 참조 12개 전체와 비교해 점수를 매깁니다. 방법의 핵심인 **R1-WAW**(랭크 1 작성자 적응형 화이트닝)는 여러 작성자가 공유하는 기준을 매개변수 하나로 각 작성자에게 맞추므로, 참조 12개로 충분히 추정할 수 있습니다.

구현은 공개하지 않습니다. 검증 엔진은 컴파일된 형태로 제공됩니다(`backend/sigdesk_engine/engine.pyc`, Python 3.14).

### 데이터셋

| 데이터셋 | 문자 | 개발 작성자 |
|---|---|---|
| CEDAR | 라틴 문자 | 25 |
| BHSig260 Bengali | 벵골 문자 | 45 |
| BHSig260 Hindi | 데바나가리 | 72 |

등록: 진짜 1–12. 테스트: 진짜 13–24와 위조 1–12. 172명의 작성자는 단 한 번의 최종 평가를 위해 보류되어 있습니다.

### 결과 (개발 세트, 작성자 142명)

| 거리 척도 | AUC | EER |
|---|---|---|
| B — 전역 대각 | 0.772 | 25.8% |
| G — 통합 전체 공분산 | 0.831 | 22.0% |
| **J — 랭크 1 작성자 적응** | **0.837** | **21.3%** |

| 데이터셋 | J AUC | J EER |
|---|---|---|
| CEDAR | 0.839 | 21.3% |
| BHSig260 Bengali | 0.801 | 25.4% |
| BHSig260 Hindi | 0.858 | 18.8% |

작성자 단위 대응 비교로 Wilcoxon 검정, Holm 보정, 부트스트랩 구간을 사용. J 대비 G: AUC +0.006 (개선 53명, 악화 13명, 변화 없음 76명).

> **상태:** 초안. 결과는 개발 작성자에 대한 것뿐이며, 보류 세트 평가는 아직 수행하지 않았습니다. 벵골어에서는 이미지 통계 대조군이 모델과 비슷한 성능을 보이므로 벵골어 결과는 서명 검증으로 보고하지 않습니다.
